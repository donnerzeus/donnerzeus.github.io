# Barış Delikaya Portfolio

Personal portfolio site built with React and Vite, deployed through GitHub Pages.

## Stack

- React 19
- Vite
- Framer Motion
- Lucide React

## Local development

```bash
npm install
npm run dev
```

Recommended Node.js version: `20.19+` or newer.

## Production build

```bash
npm run build
```

Vite outputs the static site into `docs/`, which is used for GitHub Pages deployment.
